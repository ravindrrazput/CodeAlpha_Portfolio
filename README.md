# Ravindra Singh | Personal Portfolio

A modern and responsive personal portfolio website built using HTML5, CSS3, and JavaScript. It showcases my educational background, technical skills, projects, resume, and professional journey.

## Live Demo

[Visit My Portfolio](https://ravindrrazput.github.io/CodeAlpha_Portfolio/)

## About the Project

This portfolio website represents my journey as a Computer Science Engineering student and aspiring software developer. It provides an overview of my skills, academic background, completed projects, and ways to connect with me.

## Features

- Modern and clean user interface
- Fully responsive design
- Interactive navigation bar
- About Me section
- Education details
- Technical skills showcase
- Featured projects with GitHub links
- Live project demonstrations
- Downloadable resume
- Social media integration
- Contact form with input validation
- Smooth scrolling and animations

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts and responsiveness
- JavaScript – Interactivity and functionality
- Font Awesome – Icons
- Google Fonts – Typography

## Run Locally

1. Clone this repository:

```bash
git clone https://github.com/ravindrrazput/CodeAlpha_Portfolio.git
```

2. Open the project folder:

```bash
cd CodeAlpha_Portfolio
```

3. Open `index.html` in your browser or use VS Code Live Server.
